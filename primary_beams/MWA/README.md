# MWA beams

## mwa_full_EE_test.h5

An extract of the MWA full embedded element (FEE) beam file (available at
http://ws.mwatelescope.org/static/mwa_full_embedded_element_pattern.h5)
used for testing. Contains only 3 frequencies.


## JMatrix_3freq.fits

An extract of the average embedded element dipole jones matrix containing only
3 frequencies.
Sourced from:
https://github.com/MWATelescope/mwa_pb/blob/master/mwa_pb/data/JMatrix.fits


## ZMatrix_3freq.fits

An extract of the dipole coupling matrix, used in the average embedded element
MWA beam model containing only 3 frequencies.
Sourced from: https://github.com/MWATelescope/mwa_pb/blob/master/mwa_pb/data/ZMatrix.fits
